# 家庭财务管家 🏠

家庭月度记账与资金分配工具（单文件网页应用，无需安装，打开即用）。

## 功能

- **月度表**：按月录入收入（老公/老婆/现金）、本月支出、消费统计，存款自动建议，盈余自动计算
- **存款归属**：按双方开销反比自动分配存款到老公/老婆名下并累计
- **资金池**：预算（📦 钱还在）/预支（🪙 已花掉从总资产扣除）两类资金池，盈余手动分配
- **三模块视图**：👨 老公 / 👩 老婆 / 🏠 家庭，各自存款、自由资金、资金池一目了然
- **趋势图**：收入/支出/存款/盈余月度变化、资金池余额走势
- **资产配置清单**：理财产品类/股票类/定期存单等自定义清单

## 使用说明

1. 打开页面，先「初始化」盘点家庭现有资产（各卡余额、现金、定期/理财、存量存款归属、资金池现状）
2. 每月在「月度表」填数据，点底部「✅ 确认本月数据」一次性生效
3. 数据保存在**浏览器本地**（localStorage），换设备请用「设置 → 导出备份 / 导入」

## 隐私说明

所有数据仅存于浏览器本地，不上传任何服务器，代码开源可自查。
